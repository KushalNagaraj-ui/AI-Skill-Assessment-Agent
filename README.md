# 🚀 AI Skill Assessment & Learning Agent

An AI-powered system that evaluates candidate resumes against job descriptions and provides intelligent insights.

> Built for Catalyst Hackathon – focuses on real skill evaluation, not just keyword matching.

---

## 🔥 Features

### 👤 Candidate Mode
- Resume analysis
- Skill gap detection
- AI-powered suggestions for improvement

### 🧑‍💼 Recruiter Mode
- Multi resume upload
- Candidate ranking based on relevance
- Recruiter chatbot for quick insights
- Job Description (JD) generator

---

## 🧠 Tech Stack
- Python
- Streamlit
- Sentence Transformers
- Ollama (Mistral)

---

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
