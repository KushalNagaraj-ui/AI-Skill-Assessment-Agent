# 🚀 AI Skill Assessment & Learning Agent

An AI-powered system that evaluates candidate resumes against job descriptions and provides intelligent insights.

## 🔥 Features

### 👤 Candidate Mode
- Resume analysis
- Skill gap detection
- AI suggestions

### 🧑‍💼 Recruiter Mode
- Multi resume upload
- Candidate ranking
- Recruiter chatbot
- JD generator

## 🧠 Tech Stack
- Python
- Streamlit
- Sentence Transformers
- Ollama (Mistral)

## ▶️ Run
pip install -r requirements.txt
streamlit run app.py
